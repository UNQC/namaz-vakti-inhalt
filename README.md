# Namaz Vakti – Tagesinhalt

Öffentliche Ablage für den täglichen Inhalt (Ayet, Hadis, Dua) der App **Namaz Vakti**.
Ein GitHub-Workflow ruft ihn jede Nacht über die Awqat Salah API ab und speichert ihn in `daily.json`.
Ältere Tage liegen unter `archive/`.

Quelle aller Texte: **T.C. Diyanet İşleri Başkanlığı**. Die Zugangsdaten liegen ausschließlich als Repository-Secrets vor.
